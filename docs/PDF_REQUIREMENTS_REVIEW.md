## API 키 적용 및 모델 호환성

사용자가 제공한 api-keys.txt의 키는 출력하지 않고 Windows DPAPI CurrentUser 저장소로 가져왔습니다. 원본 평문 파일은 사용자 파일이므로 임의 삭제·수정하지 않았습니다. 앱은 원본 파일을 자동으로 읽지 않고 암호화 저장소를 사용합니다.

원본 파일의 모델 gemini-2.5-flash는 실제 API가 신규 사용자에게 더 이상 제공되지 않는다고 404를 반환했습니다. 모델 목록 조회는 200으로 통과했지만 목록에 있는 것이 생성 가능성을 보장하지 않음을 확인했습니다. API 안내 모델 gemini-3.8-flash는 반복 과부하로 검증에 실패하여 접근 가능한 gemini-3.1-flash-lite로 전환했습니다. 이 모델의 실제 영상 기반 구조화 분석과 로컬 검증이 최종 통과했고 앱 설정·신규 기본 모델에 반영했습니다. 초기 최소 요청은 503 과부하, 첫 전체 요청은 타임아웃이었으며 이를 성공으로 처리하지 않았습니다. 최종 결과는 TEST_REPORT.md 참조.

Gemini 3 계열에 low thinkingLevel, 출력 최대 2048토큰을 설정하고 JSON Schema에 댓글 40~120자 및 원문에서 추출한 근거 후보 enum을 명시했습니다. 초안의 로컬 검증 실패 시 실패 이유를 전달하여 최대 2회만 다시 생성하며, HTTP 오류에는 자동 재시도하지 않습니다. 모델 이름은 설정에서 계속 변경할 수 있습니다. 근거·길이 검증 실패 시 성공 초안을 꾸며내지 않습니다.
