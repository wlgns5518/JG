# 2~3분 시연 구성

사전 준비: Windows x64 설치, Chrome 설치, API 키 입력, 사용할 프로필 직접 로그인, 실제 게시 대상과 댓글의 적절성 확인. API 할당량과 모델 접근 권한 확인. 실제 게시를 원하지 않으면 최종 승인에서 취소합니다.

| 시간 | 동작 | 설명 |
|---|---|---|
| 0:00~0:20 | 대시보드 및 설정 | 3열 구조, DPAPI 키, 모델과 상한 |
| 0:20~0:50 | 연애 키워드 검색·영상 선택 | 최신순/조회수순, 실제 메타데이터, 페이지네이션 |
| 0:50~1:30 | AI 분석 | 인기 댓글, 자막 미확보, 제목/설명 근거, 홍보 표시 댓글 |
| 1:30~1:50 | 댓글 수정·저장 | 글자 수, 링크 금지, 인용 근거 유지 |
| 1:50~2:30 | 프로필·승인·게시 | 실제 계정 핸들과 영상/댓글 최종 확인; 승인 또는 취소 |
| 2:30~2:50 | 결과·이력 | 성공 링크 또는 실패 이유, 재게시 차단, 일일 시도 수 |

실패를 숨기거나 모의 데이터를 실제 API 성공으로 설명하지 않습니다. 녹화 영상 자체는 아직 제작하지 않았습니다.
